**Date**: 2026-08-31

**Source**: conversation

## 沟通与执行方式（2026-08-31 会话反馈）

- **能力受限时不要长篇解释**：用户对「解释技术边界」非常不耐烦（原话：「你哪里没有什么写入能力，分明是瞎说」）。正确做法：一句确认 → 直接给替代方案 → 立刻执行，把解释压到最短。
- **用户主动改需求时立即切换**：不恋旧方案。例：用户说「不要你截图了，直接生成告诉我在哪里插入」→ 当即放弃截图流程，改为直接生成产物并告知插入位置。
- 一句话画像：**结论先行、直接执行、方案切换零拖泥带水**。
